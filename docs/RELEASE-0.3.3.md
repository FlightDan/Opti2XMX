# Opti2XMX 0.3.3

When selecting the upscaler frame-generation input, the interface now asks users to disable in-game frame generation to avoid overlapping paths. For FSR and DLSS frame-generation inputs, it instead tells users to enable the corresponding in-game setting. The guidance is available in Chinese and English.

This is a guidance change; it does not change game settings or fix a confirmed driver defect. Frame generation remains experimental. The final release has not received physical-device acceptance or installer/maintenance upgrade validation.

## 中文摘要

选择超分输入时，提示先关闭游戏内插帧，避免两套插帧冲突；选择 FSR 或 DLSS 输入时，提示开启游戏内对应的帧生成。支持中英文。

本次只修改提示，不会自动更改游戏设置，也不代表已修复底层驱动问题。最终版本尚未完成实机及安装器／维护升级验收。
